# 圣诞光屿 · Christmas Memories

用一只手控制的圣诞粒子与照片互动场景，采用 Three.js 和本地 MediaPipe Gesture Recognizer。无需安装前端依赖，提供可直接打开的离线单文件。

## 打开

下载完整仓库，在 Chrome 或 Edge 中打开 **圣诞光屿.html**，允许摄像头权限即可。页面自动识别，不显示摄像头画面。

如果浏览器限制本地文件的摄像头权限，安装 Node.js 后在仓库目录运行：

~~~powershell
node server.cjs
~~~

然后打开 http://127.0.0.1:4183/ 。Windows 也可双击「启动预览.cmd」。服务只监听本机。

## 手势与效果

| 动作 | 效果 |
| --- | --- |
| 握拳 | 粒子聚合为圣诞树 |
| 张开手掌 | 树炸开为立体星团 |
| 张掌左右、上下移动 | 双轴直接拖动，均可累计超过 360° |
| 张掌远离摄像头 | 星团放大 |
| 张掌靠近摄像头 | 星团缩小 |
| 竖大拇指，其余四指收拢 | 弹出照片，持续保持仅触发一次 |
| 明确放下拇指再抬起 | 切换下一张，循环浏览 |
| 照片中持续握拳约 0.65 秒 | 返回圣诞树；短暂握拳只释放翻页动作 |
| 照片中张掌 | 返回星团 |

手停在任何位置，朝向和远近保持不变；没有自动旋转和惯性续转。手离开后暂停控制，恢复时重新确认，避免跳转。飘雪与微光闪烁持续，有限的聚散过渡结束后，其余几何保持静止。

首次竖拇指选择中央附近照片。放下较久、已回到树形时，再抬起仍继续下一张；重新导入照片后重置浏览顺序。比心、OK、普通捏合和胜利手势不作为照片命令。

## 照片

点击「添加照片」多选本地图片。首次成功导入替换 12 张程序绘制的示意卡片，之后可追加。最多 36 张，每张不超过 20 MB，支持浏览器可解码的 JPG、PNG、WebP、AVIF 和 GIF 静态帧；HEIC 请先转换。

照片保持比例，导入时最长边缩至 1400 像素。只保留在当前页面内存，刷新后需重新导入。仓库不包含用户照片、参考视频或测试图片。

## 离线与稳定性

- 代码、WASM 和模型均存放在仓库；单文件中也已内嵌，不从 CDN 或远程识别服务加载。
- 摄像头和照片在本地处理，不上传，不扫描本地文件。
- 同步识别在 CPU classic Worker 中运行，避免阻塞粒子绘图。
- Worker 引导代码内联、WASM 通过内存字节初始化，移除对主文档 Blob 资源 URL 的依赖。
- 推理超时终止并有限重建，视频回调失效时回退，前后台恢复后重新确认；图形资源丢失时尝试恢复。
- 实际响应取决于设备、光线、距离和手部角度。首次使用需要浏览器摄像头授权；无法绕过系统权限。

## 源码与构建

主要文件：app.js（场景）、hand-controller.js（采集和调度）、gesture-worker-client.js（独立识别线程）、pose-resolver.js／gesture-interpreter.js（姿态与时序）、palm-rotation.js／palm-depth.js／hand-motion.js（旋转、推拉及静止判断）。

源码预览使用 index.html 和同目录 vendor/。修改源码后重新生成单文件：

~~~powershell
node build-standalone.cjs
node build-standalone.cjs --write
~~~

第一条只检查和显示计划，第二条才写入「圣诞光屿.html」。构建器校验本地资源哈希，不安装依赖、不下载组件。
